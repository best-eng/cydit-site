# Cydit site

Статический сайт Cydit — без зависимостей и сборщика. Двуязычный (RU/EN).
Дизайн взят из приложения: палитра, радиусы и шрифт — из его темы, скриншоты — с бета-сборки.

## Запуск

Проще всего поднять локальный сервер в папке сайта:

```bash
python -m http.server 8137
```

Дальше — http://localhost:8137.

## Структура

- `index.html` — разметка и весь русский текст.
- `app.js` — английский текст (`en`), переключение языка, вкладки экранов, форма.
- `styles.css` — стили и адаптив. Цвета собраны в `:root`.
- `assets/brand` — знак, фавиконки, картинка для соцсетей.
- `assets/screens` — скриншоты приложения (720 px по ширине, WebP).
- `assets/img/mountain.webp` — фон с горами из приложения.
- `assets/fonts/Manrope-var.woff` — Manrope из приложения, латиница и кириллица.

## Тексты

Русский текст правится прямо в `index.html`. У каждого переводимого элемента есть `data-i18n="ключ"`; английская строка с тем же ключом лежит в объекте `en` в `app.js`. Если поменять русский текст, английский нужно поправить там же.

## Контакты и форма

В начале `app.js`:

```js
const CONFIG = {
  email: 'hello@cydit.app',
  telegram: 'https://t.me/cydit',
  waitlistEndpoint: '',
};
```

Пока `waitlistEndpoint` пустой, форма раннего доступа открывает готовое письмо на `email`. Чтобы заявки собирались сами, укажите адрес обработчика: форма отправит на него `POST` с JSON `{ email, lang, source }` и покажет подтверждение при ответе 2xx.

## Перед публикацией

- В `index.html` у `og:image` указать полный адрес картинки на боевом домене — соцсети не читают относительные пути.
- Проверить почту и Telegram в `CONFIG`.
